## 10. 最终核对

- [ ] 未新增无法验证的事实、数据或来源
- [ ] 未改变因果方向、统计含义或适用范围
- [ ] 引文、页码、引用键和直接引语完整
- [ ] 术语、缩写、变量和单位一致
- [ ] 标题、表图、公式和交叉引用保留
- [ ] 未通过故意错误或随机变化伪装写作来源
- [ ] 满足用户明确规定的最低字数/词数
- [ ] 未以删除大部分内容代替深度编辑
- [ ] 每节独有机制、限制和方法学信息仍在
- [ ] 未把原模板替换成统一的“机制—否定—未来研究”模板
- [ ] 未仅靠轮换 claim、boundary、recommendation 顺序伪造章节功能差异
- [ ] 多数章节没有相同段数和相同段落句数几何
- [ ] 纠正式否定没有取代肯定、具体的证据综合
- [ ] 未反复使用“作者判断/central judgement/bounded synthesis”等裁判式元话语
- [ ] 各节结尾不全是边界、建议或审稿式判词
- [ ] 成稿正文不含“原稿”“修订稿”“supplied text”“SOURCE REQUIRED”等编辑过程残留
- [ ] 已检查目标机构或期刊的 AI 使用与披露规则
