# Academic DeAI 社交宣传与合成案例包

制作日期：2026-10-04。历史案例执行版本：Academic DeAI 3.0.0。此标识不代表本次发布的新版本。

此目录是导入仓库的宣传演示素材。编辑规则与具体模型无关，适用于各 Agent 平台的最新模型；平台需支持 Skill 或加载编辑指令。尚未逐平台、逐模型验证编辑表现，当前加载方式见[Agent 平台说明](https://github.com/heise3/academic-deai/blob/main/docs/agent-platforms.md)。

本包包含可发布的中文文案、四组完整合成案例、六张社交图文卡片及核对记录。

## 演示如何制作

先由模型编写四份刻意加入模板化表达的原稿。两个不继承本次宣传上下文的编辑回合，读取本地 Skill 及相关参考后，各编辑两例。另一个模型回合先只读原稿提取41条命题，之后比较修订稿。

编辑回合保留原章节、实质主张与合成声明；审稿回复允许删冗余背景。Skill由语言模型执行，内容锁脚本辅助检查数字、引文等可观察项，不生成改写。核对发现技术综述将“未下降”写成“保持不变”，已由原编辑回合针对性修正，记录保留了发现与修正过程。

这是当前会话中的分开编辑与核对，不是独立人工盲评。没有指定另一个模型checkpoint，也没有设置其他工具的对照组。

## 使用这些材料时

所有研究、数据、设备数量、引文编号和投稿改动均为虚构，仅用于语言编辑演示。保持文案和配图中的合成示例标识。

案例展示本次输入与输出，不证明真实稿件上的平均效果、检测率变化或其他工具的排名。数字与引文检查通过，也不能证明语义完全一致。41条命题核对只覆盖本清单，不能替代真实稿件的作者审阅。

本次是四个新宣传案例，与[历史 Skill 发布验证记录](https://github.com/heise3/academic-deai/blob/main/docs/validation.md)中的八个前向案例不同，不合并样本数。导入保留四例原稿和修订稿的字节及 SHA-256，只更新展示文档、宣传配图和制作记录。3.0.0 只表示历史案例执行版本；配图中的发布版本不表示重新执行了这些案例。
